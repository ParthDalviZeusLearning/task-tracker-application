# Task Tracker Application 

## Overview of the Application 
The Task Tracker Application is a simple web-based application that allows users to track their day to day tasks efficiently.It is developed using HTML,CSS and JavaScript.It allows users to add tasks, view the list of pending tasks, mark tasks as "Completed",delete tasks,edit tasks and view the list of completed tasks and storing data using browser Local Storage.


##  Features Completed 
- Add Tasks                   
- View Pending Tasks   
- Mark Tasks as "Completed".
- Delete Tasks 
- Persistent data storage using Local Browser
- Edit Task Functionality
- Alerts if Empty tasks are entered
- Confirmation Pop-Up before task deletion
- Add Due Date to tasks
- View the count of Completed and Pending tasks 
- Add Descriptions of Task 


## Additional Features Implemented

- Added drag-and-drop functionality to reorder tasks. 
- Updated the task order in the UI immediately after dropping a task. 
- Saved the updated task order so it remains available after refresh. 
- Made UI responsive for Touch devices

## How to run the project 

Step 1: Download or clone the project.
Step 2: Open the project folder in Visual Studio Code.
Step 3: Install the "Live Server" extension in VS Code.
Step 4:Right Click on "index.html"
Step 5: Click "Open with Live Server".
The application will open in the browser.
